# Stage4 producer and independent checks

The adopted workflow runs only after Stage3 independent scientific validation and verified GitHub publication. Alignment and inference are separate phases, with a separate alignment/partition validation report required before any topology. Publication remains a separate root-owned gate after final Stage4 validation. The checked Stage3 publication receipt hash is recorded in the mutable launch receipt; it is kept out of the immutable scientific computation identity.

The current view is the independently validated topology-blind orthology-v2 projection. The original101 markers/19551 accepted sequences retain their executed source/filter integrity proof and scientific duplicate-signal blockage. Full MiaA loci shared by IPPT/IPT192 times are resolved by excluding the entire redundant IPT family, retaining IPPT across196 assemblies. The curated100 profiles/19359 sequences require both original119-profile/196-genome filters and the additional unique-length96 recovery gate; no HMM search is repeated. Producer and independent Stage4 reader check the exact source-row subtraction, retained locus uniqueness and config/curation/certificate hashes. [CONTROLLER.md](CONTROLLER.md) supplies the explicit current/original paths and resumed Windows command.

Before alignment the producer freezes the exact196 panel, exact preserved G0 sensitivity162 membership, the155 assemblies reported Complete Genome/Chromosome in the frozen panel metadata, and the primary markers with accepted occupancy at least187/196. The primary sorted marker order comes from Stage3. Sensitivity lists never replace the approved primary panel. All four lists, code/config/source hashes, resource settings and actual tree options are frozen in `analysis_freeze.json` before topology.

Each accepted primary marker is aligned once with MAFFT7.526 `--auto --thread 2`, then trimmed once with trimAl1.5.rev1 `-automated1 -fasta -keepheader -keepseqs -colnumbering`. The header-preserving flag retains accession punctuation; sequence retention prevents an all-gap trimmed row from being silently removed. Any marker with no retained columns or genome with an all-gap concatenation is a blocker. Present markers whose entire sequence is trimmed remain explicit in QC and source-block states. The raw native FASTA bytes, command stdout/stderr, source proteins and native trimAl column map are preserved.

The actual trimAl map was verified on a hand-written synthetic alignment: its `#ColumnsMap` line lists zero-based raw-column indices. The producer and independent checker both reconstruct every trimmed sequence from those columns. The checker separately imports aligned FASTA, CLUSTAL, relaxed PHYLIP and NEXUS using BioPython and requires full accession/sequence agreement. No trimmed fragment hash is used to guess an original protein identity.

All concatenations use the same primary marker alignments and frozen profile order. The162/155 sensitivities select rows; the187-marker sensitivity selects blocks. Missing marker cells get a gap block of the exact partition width. Natural alignment gaps and present-but-entirely-trimmed rows are reported separately. There are no synthetic spacer residues. Partition TSV, NEXUS and RAxML-style coordinate files cover each concatenation exhaustively with no overlap. The independent checker reconstructs every exact assembly+marker block and its accepted source-locus/hash join.

The installed IQ-TREE3.1.4 command uses `--seqtype AA -p partitions.nex -m MFP -B 1000 --alrt 1000 --seed 1961008 -T 2 --mem 1536M -keep-ident --boot-trees`. The actual native help identifies `-p` as the edge-linked proportional model. ModelFinder runs per partition without `--merge` or `MFP+MERGE`; the final checker requires the actual selected per-partition model scheme. [IQ-TREE's partition documentation](https://www.iqtree.org/doc/Complex-Models) describes the proportional model and partition files. [Its command reference](https://iqtree.github.io/doc/Command-Reference) documents retaining identical sequences; the installed binary accepted `-keep-ident` in a negative missing-input argument probe, with no inference executed.

`-keep-ident` keeps every named assembly during inference. Identical concatenated sequence groups are reported because host markers cannot independently resolve their relative strain placements. Any native omission of support on a zero-length branch inside a truly identical-alignment group is retained as `NOT_REPORTED_BY_NATIVE_TOOL_IDENTICAL_ALIGNMENT_GROUP`; no support value is invented. Other missing combined internal supports are a blocker. The independent checker parses all1000 actual UFBoot trees and checks exact membership in each.

Both phases require two-core affinity and a2GiB process address-space cap. A separate measured resource receipt must declare `maximum_compute_threads:2`, `iqtree_memory_mib:1536` (or a lower measured setting), `process_address_space_limit_bytes:2147483648`, and actual `measured_windows_available_bytes`/`measured_linux_available_bytes` above2GiB. IQ-TREE's1536MiB request leaves address-space headroom beneath the outer cap. CPU/elapsed and cumulative child peak RSS are recorded; the caller's `/usr/bin/time -v` measures the whole process. No automatic memory relaxation occurs on failure.

Successful per-tool receipts bind exact input/code/environment identity and preserve hashes. A verified actual exit0 command can be recovered after an interrupted post-process checkpoint write. Partial MAFFT/trimAl attempts are retained; a completed valid alignment is never recomputed. IQ-TREE restarts with the identical argv/prefix and its native checkpoint; no `--redo` or `--redo-tree` is supplied. Two analyses with byte-identical concatenations and partitions reuse a completed inference explicitly rather than duplicate it. Failed or identity-changed states preserve evidence and block automatic cache reuse.

No outgroup references have been retrieved or scientifically validated in the current cohort. Tree files are explicitly treated as unrooted; the script supplies no outgroup/root argument, copies the raw topology into portable Newick/NEXUS, and reports root uncertainty. Labeled Newick/NEXUS copies replace exact accession name tokens with frozen display labels plus the accession, retaining original branch/support text. Apostrophes/newlines are normalized only in the portable display label; the exact source display text remains in `tip_label_map.tsv`. Final checks compare unrooted sensitivity bipartitions on shared tips and compare frozen metadata groups to tree splits without manual tree edits. Optional gene/site concordance is recorded `NOT_RUN`; it is not claimed by the mandatory ML/support work.
