# Same-data single-model IQ-TREE fallback resource policy

Recommend a3.5GiB native process and aggregate job committed-memory cap, plus1.5GiB host reserve: fresh available physical RAM AND Windows commit headroom must each be at least5GiB. Use the unchanged196×17456AA matrix, full MFP selection,1000UFBoot/1000SH-aLRT, seed1961008 and two threads. Add the supported allocation flags `--mem 2G --thread-site` only for this unpartitioned fallback. These flags alter cached likelihood storage and candidate execution scheduling, not the dataset or model candidate set.

Independent input reread found14012 unique raw column patterns. Translating the pinned v3.1.4 `PhyloTree::getMemoryRequired` formula yields4.176GiB core likelihood/bootstrap storage at10rate categories in ordinary mode. With `--mem 2G`, cached likelihood slots decrease from194to90 and core storage becomes1.988GiB. Adding explicit G-matrix/theta/category/pattern arrays plus an oversized128MiB traversal/parsimony allowance gives2.176GiB. A3.5GiB external cap leaves1.324GiB beyond that structural estimate for model/checkpoint/heap/runtime uncertainty. Source code and hashes, calculations and qualifications are in `fallback_memory_evidence.json`.

This is a conservative bounded allocation policy, not measured peak memory or evidence of successful inference. The native job cap must remain the hard limit; IQ-TREE `--mem` does not bound its complete process heap. A cap allocation failure must be explicit. A3GiB cap is not independently recommended here. The partitioned preferred analysis retains its separate4.5GiB cap plus1.5GiB reserve.

The undocumented `-memcheck` flag exists in v3.1.4 but is unsafe as a no-inference MFP probe: [startTreeReconstruction](https://github.com/iqtree/iqtree3/blob/v3.1.4/main/phyloanalysis.cpp) calls ModelFinder before runTreeReconstruction tests memCheck, and [ModelFinder](https://github.com/iqtree/iqtree3/blob/v3.1.4/main/phylotesting.cpp) performs initial fast ML/NNI computation. No data-bearing IQ-TREE invocation was performed for this assessment. The allocation formula is in the [pinned PhyloTree source](https://github.com/iqtree/iqtree3/blob/v3.1.4/tree/phylotree.cpp), and flag parsing is in the [pinned option parser](https://github.com/iqtree/iqtree3/blob/v3.1.4/utils/tools.cpp).
