# Identical aligned sequences and IQ-TREE 3.1.4 support labels

Source-only review, 2026-10-09. No inference, WSL boot, running-producer edit, or tree-checker edit was performed. This is implementation evidence, not a validation of the still-running native result.

The official [v3.1.4 release](https://github.com/iqtree/iqtree3/releases/tag/v3.1.4) resolves through the GitHub tag API to commit `63c330d90dd02241dbbbaf1e9f9e9cc6dadbd1de`. Six relevant source files were retrieved from that exact commit into `work/iqtree_3_1_4_source_review/`; their byte hashes are in `source_pin.json`. The running Windows executable remains independently pinned by the existing launch configuration; a source-tag inspection alone does not prove a binary was built from that commit.

## Source findings

- [`utils/tools.cpp` lines 1536–1538](https://github.com/iqtree/iqtree3/blob/63c330d90dd02241dbbbaf1e9f9e9cc6dadbd1de/utils/tools.cpp#L1536-L1538) makes `-keep-ident` set `ignore_identical_seqs=false`. [`main/phyloanalysis.cpp` lines 5354–5385](https://github.com/iqtree/iqtree3/blob/63c330d90dd02241dbbbaf1e9f9e9cc6dadbd1de/main/phyloanalysis.cpp#L5354-L5385) therefore bypasses duplicate removal and has no removed taxa to reinsert afterward. All 196 input taxa participate in this retained-sequence mode.
- [`PhyloTree::testAllBranches`, lines 5452–5496](https://github.com/iqtree/iqtree3/blob/63c330d90dd02241dbbbaf1e9f9e9cc6dadbd1de/tree/phylotree.cpp#L5452-L5496) tests every traversed edge whose two endpoints are internal and writes a numeric SH-aLRT label. There is no duplicate-sequence or branch-length exemption in this traversal. [`testOneBranch`, lines 5354–5449](https://github.com/iqtree/iqtree3/blob/63c330d90dd02241dbbbaf1e9f9e9cc6dadbd1de/tree/phylotree.cpp#L5354-L5449) derives support from alternative NNI likelihoods and resampling. For exact likelihood ties its strict comparison with a 0.05 margin contributes no SH-aLRT successes; this does not justify predicting every duplicate-associated support as exactly zero in the actual numerical run.
- [`MTree::createBootstrapSupport`, lines 2734–2780](https://github.com/iqtree/iqtree3/blob/63c330d90dd02241dbbbaf1e9f9e9cc6dadbd1de/tree/mtree.cpp#L2734-L2780) appends the UFBoot split frequency to an existing label with `/`; a split absent from the bootstrap split map receives explicit `0`, not an omitted field. [`IQTree::summarizeBootstrap`, lines 3995–4036](https://github.com/iqtree/iqtree3/blob/63c330d90dd02241dbbbaf1e9f9e9cc6dadbd1de/tree/iqtree.cpp#L3995-L4036) invokes this after SH-aLRT. The online selection code [lines 3914–3926](https://github.com/iqtree/iqtree3/blob/63c330d90dd02241dbbbaf1e9f9e9cc6dadbd1de/tree/iqtree.cpp#L3914-L3926) randomly selects among sufficiently close RELL candidates; duplicate-associated UFBoot values are not hardcoded to zero.
- The separate default removal path keeps two representatives per duplicate group, then [`MTree::insertTaxa`, lines 2847–2877](https://github.com/iqtree/iqtree3/blob/63c330d90dd02241dbbbaf1e9f9e9cc6dadbd1de/tree/mtree.cpp#L2847-L2877) creates unnamed internal nodes with zero terminal lengths during reinsertion. That explains a genuine potential for unlabeled added nodes in other command modes, but does not authorize an exception for the current `-keep-ident` command.
- [`main/phyloanalysis.cpp` lines 3969–4007](https://github.com/iqtree/iqtree3/blob/63c330d90dd02241dbbbaf1e9f9e9cc6dadbd1de/main/phyloanalysis.cpp#L3969-L4007) skips SH-aLRT on a multifurcating tree and emits a warning. Near-zero collapse is a separate optional operation after support assignment; the pinned argv does not request it and its default is false. Optimized near-zero lengths may sit at the positive minimum (here default 1e-6), so exact duplicate strings do not require literal zero branch lengths.

## Acceptance and scientific interpretation

Keep the current paired SH-aLRT/UFBoot requirement for every nonroot internal edge. Source review found no current-mode duplicate exception. Inspect the actual final Newick, executed-test log, and 1000 full 196-taxon bootstrap trees after native closure. Missing labels or a multifurcation warning require explicit diagnosis against the pinned source and actual artifacts; do not manufacture supports or silently weaken the checker. Numeric zero already satisfies its 0..100 range.

The independent accepted-alignment QA reports 196 taxa, 17456 columns, 182 distinct complete aligned strings, and 8 exact-duplicate groups containing 22 taxa (sizes 5, 4, 3, 2, 2, 2, 2, 2). Its JSON SHA256 is `f53e8af8d55a30b41b521e9c51a86bb8d2d37ddeb59b91586a6a27c89b8ad309`. These are 182 sequence equivalence classes, not 182 independent genomes or taxa. Keep all 196 accession labels in the accepted tree, matrices, and joins.

The alignment provides no sequence difference to resolve the relative ordering of members within an exact-duplicate class. Any displayed bifurcation there must be described as unresolved by these host-marker data; even a large computed support does not create distinguishing characters. Distinguish support for an entire group versus another lineage from support for its within-group ordering. R-M differences may still exist outside these 17456 aligned host-marker positions and remain genome-level observations. A later display may annotate these equivalence classes, while preserving the unmodified accepted 196-tip tree and complete accession mapping.

The official [FAQ](https://iqtree.github.io/doc/Frequently-Asked-Questions#how-does-iq-tree-treat-identical-sequences) explains why an identical group's bootstrap support need not be 100%: resampling can make another sequence indistinguishable from the group. Its support-interpretation section also cautions that common single-gene SH-aLRT/UFBoot cutoffs do not transfer automatically to concatenated phylogenomic trees. No new concordance-factor or alternative inference run is authorized or required by this review.
